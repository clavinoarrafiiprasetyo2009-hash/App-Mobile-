Aplikasi Smart Lost & Found Sekolah | Spesifikasi Terpadu Frontend, Backend, Database PostgreSQL & Deployment

1. Gambaran Umum Alur Arsitektur System

Aplikasi SiTemu dibangun menggunakan arsitektur Single Page Application (SPA) modern yang terhubung secara real-time ke Cloud Backend (Supabase BaaS).

📱 Frontend (React 18 + Vite)   ➔   ☁️ Vercel CDN   ➔   ⚡ Supabase Cloud API   ➔   🐘 Database PostgreSQL

2. Arsitektur Frontend (Client-Side)

Core Technology Stack:

  • Framework Utama: React 18 (Functional Components, Hooks: useState, useEffect, useRef)
  • Build Tool: Vite 5.4 (Superfast HMR & Production Bundler)
  • Icons & Design System: Lucide React + Vanilla CSS3 Design Tokens
  • Mobile Frame Dimensions: Locked Shell 390px x 830px (Responsif 100vw pada layar HP Android/iOS)

Fitur Unggulan Frontend:

  1. Fitur Akses Kamera HP (Native Camera API): Menggunakan <input capture="environment"> dan FileReader API untuk mengubah foto barang menjadi format Data URL / Base64 instan.
  2. Dynamic Ambient Status Glow: Warna aksen aplikasi berubah sesuai status barang (🔴 Merah = Hilang, 🟢 Hijau = Ditemukan, 🔵 Biru = Selesai).
  3. Optimasi Sentuhan Mobile: Dilengkapi aturan CSS -webkit-tap-highlight-color: transparent dan user-select: none untuk pengalaman layaknya aplikasi native.
